# Changelog

## 1.1.0

- Full workspace editor: page metadata, folders, ordering, publication, RTL/LTR, tags, table of contents, homepage, branding, themes, media, favicon, preview, and local draft recovery.
- Launcher-equivalent Git flow: safe empty-origin seeding from the official upstream, repository status, checkpoints before merges, origin synchronization, and stable official-version updates.
- Engine 4 project format, legacy settings migration, and an interactive static site shell with search, theme toggle, navigation, and generated table of contents.
- Release workflow now checks out the Engine and theme packages required to build a reproducible Windows installer.

## 1.0.0

- Initial Electron, React, TypeScript, and Vite desktop release.
- Secure preload bridge with isolated renderer and redacted main-process diagnostics.
- Engine-backed project lifecycle, validation, preview generation, migration, and publishing.
- Git clone, status, synchronization, commit, push, history, identity, and recovery workflows.
- Legacy Launcher registry import and safe legacy-project migration checkpoints.
- Theme registry packaging, media library, favicon actions, English/Hebrew direction switching, and Windows NSIS packaging.
